#Hospital Management Database
This project is designing and creating a hospital management database using MySQL.

#Database Tables
The database contains six tables:
  Department
  Staff
  Patient
  Treatment
  Appointment
  StaffLeave

#What was used
  MySQL
  Entity Relationship Diagrams (ERD)

#Features
  Created tables with primary and foreign keys.
  Created relationships between database tables.
  Added fake records to the database.
  Used SQL queries to retrieve and filter information.
  Updated and deleted database records.
  Created queries using JOIN
  Designed the database with 3NF in mind.

#Skills Demonstrated
  Relational database design
  SQL programming
  Primary and foreign key use
  Database relationships
  Data manipulation
  Database normalisation
